# Catalogue de livres

Ouvrez le dépôt dans GitHub Codespaces. Patientez, le script d’initialisation installe les dépendances, configure MariaDB, exécute les migrations et charge les livres de démonstration.

Une fois l’initialisation terminée, lancez le serveur :

```sh
php artisan serve --host=0.0.0.0 --port=8000
```
Une fois la commande lancée, faites ctrl + clic sur le "[http://0.0.0.0:8000]" qui apparait dans le terminal
L'url de votre projet est propre à votre code space. N'allez pas sur littéralement sur http://0.0.0.0:8000. 

Exemple d'url : https://obscure-cod-gxpx44g664g9cv4xx-8000.app.github.dev/
