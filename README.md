# Catalogue de livres

Projet de départ de l’examen de développement web L3 — seconde chance.

Ouvrez le dépôt dans GitHub Codespaces. Le script d’initialisation installe les dépendances, configure MariaDB, exécute les migrations et charge les livres de démonstration.

Une fois l’initialisation terminée, lancez le serveur :

```sh
php artisan serve --host=0.0.0.0 --port=8000
```

Ouvrez le port 8000 dans le navigateur pour accéder au catalogue.
